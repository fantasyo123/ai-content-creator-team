# 任务下发规范与模板

> 派发给任何成员（子代理）的任务必须携带足够信息。以下模板缺一不可，否则成员无法正确执行。

---

## 基础信息五要素（视频/图片类必须）

| 必传项 | 说明 | 示例 |
|--------|------|------|
| **生成模式** | 文生图/图生图/文生视频/图生视频/人物视频/特效视频 | "请使用图生视频模式" |
| **推荐的模型** | 具体模型名称（见 model-selection.md） | "推荐使用 hy-video-1.5" |
| **素材 URL / 路径** | 图生图、图生视频时必传；文生时省略 | "关键帧图片：/path/to/keyframe.png 或 Base64 URL" |
| **详细描述** | 画面、风格、构图、动作、光线、氛围的完整描述 | "暖色调咖啡馆，马克杯上方热气升起，镜头从杯口特写缓慢拉远…" |
| **技术参数** | 时长 / 分辨率 / 横竖屏 / 批次 | "5 秒，1080p，竖屏 9:16" |

## 文案类任务要素

| 必传项 | 说明 |
|--------|------|
| **主题** | 写什么（产品/内容/话题） |
| **目标平台** | 公众号 / 小红书 / 知乎 / 抖音口播 / 官网等 |
| **受众** | 谁看，决定语气 & 深度 |
| **格式** | 长文/短文/脚本/分镜/广告语（按 team-members.md 中对应成员的输出格式） |
| **补充** | 参考素材、字数限制、敏感词规避要求 |

## 正确示例（视频任务）

```
请生成一段产品宣传视频：
- 生成模式：图生视频
- 推荐模型：yt-video-2.0
- 关键帧图片：C:/workspace/keyframes/coffee.png
- 视频描述：画面中心咖啡杯上方热气缓缓升起，镜头从杯口特写缓慢拉远，露出咖啡店窗边
  明亮座位。电影感画面，暖色调，浅景深。
- 技术参数：5 秒，1080p，横屏 16:9
```

## ❌ 反例（禁止）

```
帮我生成一段产品宣传视频
```
（缺少模式、模型、参数，会导致成员无法执行，必须补齐）

## 成员执行后回传格式（统一结构）

成员完成任务后必须回传：
1. **产出物绝对路径**（图片 / 视频 / 文档的完整路径）
2. **执行摘要**（做了什么、用了哪些模型/参数）
3. **文件清单说明**（每个文件的用途）

## 调度异常与升级机制

- 成员 > 10 分钟未回 → 向用户通报等待状态
- 成员 > 15 分钟仍无响应 → 视为失败 → 启动备用方案
- 成员报告"超出能力范围" → 立即终止该任务线，找替代方案，**禁止重新派发相同任务给同一成员**
- 同任务连续失败 2 次 → 终止任务线，如实向用户说明并提供替代建议

## 调度 subagent 命名约定

- `name` 参数必须映射到实际成员 Agent ID，禁定义泛化的无用名字。
- 专用示例：
  - `name: "image-creator", subagent_type: "general-purpose"`
  - `name: "video-generator", subagent_type: "general-purpose"`
  - `name: "copywriter", subagent_type: "general-purpose"`
  - `name: "creative-strategist", subagent_type: "general-purpose"`
  - `name: "video-editor", subagent_type: "general-purpose"`
  - `name: "content-adapter", subagent_type: "general-purpose"`

（注：若平台可用子代理类型时优先使用；否则统一使用 general-purpose + 角色 Prompt，Prompt 中必须写清楚"你是谁，你的职责是什么、应使用哪些工具、输出什么格式"。角色 Prompt 见 team-members.md。）
