# 预设 Workflow 编排

> 触发条件与完整流程。所有流程遵循"串行依赖"铁律：前序产物未完成，禁止跳入后续阶段。
> 跨成员信息流必须经主理人中转，成员不得互相直连。

---

## Workflow 1：短视频生产流水线

**触发条件**：用户要求"生成一段 XX 视频"、"制作短视频"、"产品宣传片"等视频创作需求。

```
Phase 1【可选】：
  image-creator → 生成视频关键帧/参考图（仅当无素材且要求高品质画面时）

Phase 2【串行，核心阶段】：
  video-generator → 生成视频
    - 有参考图/关键帧 → 图生视频（YT-Video-2.0 或 HY-Video-1.5）
    - 无参考图 → 文生视频（HY-Video-1.5）【默认路径，优先保证产出】
    - 人物场景 → 人物视频（YT-Video-HumanActor）

Phase 3【可选串行】:
  video-editor → 后期处理（加字幕/水印/转场/滤镜），仅当用户有后期需求

主理人汇编 → 交付（全部视频素材 + 成片 + 关键帧图片）
```

**关键决策**：
- 用户有参考图 → 跳过 Phase 1，直接图生视频
- 用户无素材但描述详细 → 跳过 Phase 1，直接文生视频
- 用户无素材 + 明确要求高品质 → 先 Phase 1 生成关键帧，再图生视频
- 用户无素材且描述模糊 → 先向用户确认需求细节，再决定路径

## Workflow 2：图文内容批量生产

**触发条件**："生成一组图文"、"小红书种草图"、"社交媒体配图"、"批量产品图"等图文需求。

```
Phase 1【单一】: image-creator → 批量生成图片
  - 用风格锚定词（一致的关键词/场景/材质描述）保证系列图片风格一致性
Phase 2【可选】: 主理人审核质量，不满意退回优化

交付：全部图片文件 + 每张说明
```

---

## Workflow 3：视频 + 图文混合内容

**触发条件**：用户同时需要视频和配套图文，如"做一套新品上市的宣传物料"。

```
Phase 1【可并行】:
  image-creator → 生成配套图文素材
  video-generator → 生成宣传视频（若需图生视频，则先等 image 产出关键帧）
Phase 2【可选串行】: video-editor → 视频后期
Phase 3【可选串行】: content-adapter → 多语言版本/素材合成
```

**注意**：图生视频时 Phase 1 不能完全并行——image-creator 先完成，再传图片给 video-generator。

---

## Workflow 4：视频翻译与本地化

**触发条件**："把视频翻译成 XX 语言"、"做多语言版本"。

```
Phase 1【单一】: content-adapter → 视频翻译（声纹克隆 + 唇型同步）
Phase 2【可选】: video-editor → 替换/添加目标语言字幕
交付：翻译后视频 + 说明
```

## Workflow 5：图文内容创作（文章 + 配图）

**触发条件**："写一篇公众号文章"、"写长文"、"写博客"、"帮我写个深度内容"、"写篇知乎专栏"等文字需求（可含配图）。

```
Phase 1【单一】: copywriter → 完整文稿
  - 输出：完整文章 + 标题方案 + 配图建议（位置 + 描述）
Phase 2【可选并行，依赖 Phase 1 配图建议】: image-creator → 生成封面图/文中配图
  - 仅当用户明确要求配图，或文章类型适合配图时调度
Phase 3【主理人汇编】: 整合文稿 + 配图，按目标平台排版规范输出
```

**关键决策**：
- 只说"写文章"未提配图 → 仅 copywriter，跳过 Phase 2
- 说"写一篇带配图的文章" → 完整流水线
- 公众号长文默认建议配图（封面 + 文中 1-3 张），主动询问用户是否需要

## Workflow 6：视频脚本 + 视频生产

**触发条件**："帮我做个带讲解的短视频"、"写个脚本并生成视频"、"从文案到视频一条龙"。

```
Phase 1【单一】: copywriter → 脚本/分镜表（时间|画面描述 | 旁白 | 字幕）
Phase 2【串行】: image-creator → 按分镜的画面描述生成关键帧
Phase 3【串行】: video-generator → 基于关键帧生成视频片段
Phase 4【可选串行】: video-editor → 拼接片段 + 字幕/旁白/转场
```

## Workflow 7：创意策划 + 内容生产（策略先行）

**触发条件**："帮我设计一套品牌视觉"、"做一组广告创意"、"不确定要什么风格"、"帮我想创意方向"。

```
Phase 1【单一】: creative-strategist → 创意策划
  - 输出：品牌定位/情绪板文字/广告方向/镜头设计 + Prompt 建议 + 执行建议
Phase 2【按策划调度，可并行】:
  copywriter → 撰写文案（如需要）
  image-creator → 按 Prompt 建议生成图
  video-generator → 按镜头设计生成视频（如需要）
Phase 3【可选】: image-creator → 发布级精修（用户要求正式版）
```

**关键决策**：
- 用户明确知道要什么（如"画一张某风格城市"）→ 跳过 Phase 1 直接生产
- 需求模糊/综合（"帮我做品牌物料"）→ 必须走 Phase 1
- Phase 1 策划方案需完整传递至 Phase 2 执行成员

## Workflow 8：发布级精修流水线

**触发条件**："做正式版"、"发布级品质"、"需要精确文字+高品质背景"。

```
Phase 1【可选】: creative-strategist → 明确资产体系（格式/渠道/尺寸） + 确定文案/CTA/数据
Phase 2【串行】: copywriter → 精确文案/CTA/数据（确定性层内容）
Phase 3【串行】: image-creator → 生成精修背景层 + 确定性合成
  - 遵循"精确层 + 生成层"分离：Prompt 禁止含文字/Logo/数据
  - 确定性叠加文字/Logo 后导出最终版
Phase 4【可选】: image-creator → 多平台尺寸适配导出
```

**关键决策**：简单图不需要精修流程；包含精确文案 + 品牌 Logo + 数据图表的正式图才走此流程。

|---------|--------|
| 生成视频 / 宣传片 / 短视频 | Workflow 1 |
| 一组图文 / 批图 / 社媒配图 | Workflow 2 |
| 宣传物料 / 新品上市内容 | Workflow 3 |
| 翻译视频 / 多语言版本 | Workflow 4 |
| 写文章 / 长文 / 图文内容 | Workflow 5 |
| 写脚本并生成视频 / 一条龙 | Workflow 6 |
| 品牌物料 / 创意方向 / 不确定风格 | Workflow 7 |
| 正式版 / 精修 / 发布级 | Workflow 8 |
